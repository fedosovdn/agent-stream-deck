# Производительность: независимые обновления задач

Местные задачи теперь обновляются, пока удалённое подключение отвечает.
Пять полных чередующихся сравнений подтвердили это для запуска, публикации
снимка и следующего опроса OpenCode и T3. Все защитные допуски соблюдены.
Изменения выполнены по выбранному владельцем предложению; новых служб нет.

## Что исправлено и зачем

1. **Отправки изображений перекрывались и могли вернуть старую картинку.**
   Где: `src/stream-deck/controller.ts`, `renderAll` и состояние регистрации.
   Один последовательный отправитель объединяет промежуточные изменения и
   доставляет последнее; проверяет поколение и экземпляр клавиши перед отправкой.
   В одинаковой управляемой проверке при удержанной первой отправке было 4 старта,
   стало 1. После освобождения окончательная картинка приходит второй отправкой;
   раньше требовалось пятое событие. Нажатие/отпускание сохраняют исходную задачу.
   Цена: состояние доставки каждой зарегистрированной клавиши и ожидание текущего
   либо следующего прохода. При анимации медленнее 200 мс ввод больше не ждёт
   полного опустошения очереди; ошибки относятся к своему проходу. Основание:
   `measured`, искусственные задержки и логические часы, не физический экран.

2. **Одновременные старты OpenCode мешали первому созданию секрета.**
   Где: `src/opencode/source.ts`, `syncDemand` и `prepareOpenCode`.
   Повторный спрос объединяет подготовку. Незавершённая запись секрета сохраняется
   между поколениями, а подготовка сборщика остаётся отменяемой. При повторном
   старте, снятии спроса и остановке во время записи: 2 подготовки / 0 сборщиков /
   недоступный источник → 1 / 1 / готовый источник. Последний хост сохраняется.
   Цена: два ограниченных ожидания до завершения подготовки; политика защиты
   файла, таймауты и повторы не менялись. Основание: `measured`, публичные методы
   с удержанной записью временного файла. Семь связанных сценариев: 0/7 → 7/7.

3. **Медленная среда T3 задерживала готовые местные данные.**
   Где: `src/t3code/source.ts`. Каждая среда фиксирует полный проверенный снимок
   независимо. Общий прежний сигнал 1200 мс начинает только свободные работы;
   отдельного дополнительного таймера нет. Ошибка одной среды и удаление
   регистрации не возвращают старые ответы. Цена: отдельное состояние местной
   среды и до восьми SSH-сред; во время удержанного T3-запроса местная работа
   продолжает выполняться. Основание: `measured` для задержек ниже, `code` для
   организации владельцев, управляемые проверки для отмены и подтверждений.

4. **OpenCode ожидал весь удалённый круг перед публикацией местного снимка.**
   Где: `src/opencode/collector.ts` и `src/opencode/source.ts`.
   Разделены обнаружение, допуск, сбор и фиксация каждого подключения; источник
   уведомляет о готовых данных. Сохраняются первые 17 допустимых подключений,
   включая 17 местных, пределы 3 сборов и 2 SSH-обнаружений. Одно следующее
   свободное место получает ожидающая местная работа; остальные обслуживают общую
   очередь. Уже начатые удалённые работы продолжаются. Цена: состояния подключений
   и очередь допуска. При местном резерве для удалённых сборов остаются два места;
   время замедления насыщенного удалённого круга не измерено. Основание:
   `measured` для задержек, `code` и управляемые проверки для пределов и порядка.

5. **Опрос контроллера и поздние ответы Codex могли мешать другим владельцам.**
   Где: `src/stream-deck/controller.ts`, `src/codex/source.ts`,
   `src/codex/bridge.ts`, `src/codex/session-ownership.ts`.
   Codex, квоты и T3 начинают независимые работы от одного прежнего сигнала;
   отправки SDK не удерживают опрос. Закрытый мост отменяет незавершённое соединение
   и переносит только подтверждённые поля индекса в новое поколение. Это сохраняет
   подтверждение завершения и кеш, не перенося незаконченные чтения. Цена: защиты
   поколений и временная копия подтверждённых полей индекса. Основание: `code` и
   публичные регрессионные проверки; скорость настоящего renderer не измерена.

6. **Новые проверки Codex изолировали каталоги слишком поздно.**
   Где: `test/source-isolation.test.ts`, `test/session-ownership.test.ts`.
   Настоящий источник импортируется только в дочернем процессе после настройки
   пяти временных путей. Добавлены проверки копирования индекса посреди чтения и
   закрытия удержанного WebSocket. Все три обратные мутации ломают нужное
   утверждение. Цена: один дочерний процесс в полном комплекте. Основание:
   `measured` на Mac; Windows-путь проверен по исходникам, выполнение не доказано.

## Ресурсы и стоимость

Здоровые нагрузки длятся 11 секунд; по одной задаче на среду. Это проверка
максимального числа подключений, а не максимального размера каталога задач.
Ниже медианы пяти прогонов (`measured`). Память — одного процесса Node.

| Показатель | 17 местных OpenCode: до → после | 1 местная +16 SSH OpenCode +8 SSH T3: до → после |
|---|---:|---:|
| CPU процесса, мс | 243,06 → 249,66 | 271,55 → 270,72 |
| Средняя память, МиБ | 65,99 → 67,87 | 69,55 → 72,64 |
| Пиковая память, МиБ | 66,81 → 68,70 | 70,52 → 75,36 |
| Запросы HTTP | 282 → 282 | 346 → 346 |
| Обращения SSH / новые туннели | 0 / 0 → 0 / 0 | 96 / 16 → 96 / 16 |
| Пробуждения | 66 → 66 | 65 → 65 |

Смешанные 96 SSH-обращений — 16 обнаружений OpenCode и 80 запросов T3;
с туннелями всего 112 запусков SSH. Счётчик HTTP не включает их. Ранее записанные
473 HTTP смешивали здоровое окно с последующим публичным сценарием из-за общей
ссылки на изменяемый счётчик; окончательные числа пересчитаны по событиям окна.

Во время удержанной удалённой работы дополнительные запросы — цена доступных
обновлений. В 13,5-секундном окне OpenCode всего HTTP: 12 → 27 при запуске,
20 → 31 при публикации и следующем цикле. При холодном запуске также появляются
80 пробуждений и 11 циклов Codex вместо блокировки до готовности. Отдельный CPU
этого окна не измерен. Здоровый сценарий остаётся в прежних пределах.

Полная обычная сборка: 263,54 → 257,37 мс; выпускная: 259,23 → 262,10 мс.
Это защитные показатели, ускорение сборки не заявляется. Пакеты: плагин
229356 → 235511 байт (+2,68%); Windows ZIP 172140 → 173320 (+0,69%);
Mac ZIP 158295 → 159475 (+0,75%). Windows ZIP создан одним Mac-упаковщиком
на обеих сторонах; это не исполнение Windows. Авторская обложка сохранена.

Пороги `assumed`: выигрыш минимум 10%, здоровые запросы/пробуждения/пакеты
не хуже +10%; CPU max(10%,5 мс), память max(10%,16 МиБ), сборки max(10%,10 мс),
публичные операции max(10%,1 мс). Все прошли. Улучшение CPU или памяти не заявляется.
Новые платные службы не добавлены; денежная стоимость работы моделей не измерена.
